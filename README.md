# 🦜 Langchain Web & YouTube Summarizer

A Streamlit-based application that summarizes content from **websites** and **YouTube videos** using **LangChain**, **Groq API**, and **Gemma 2-9B** LLM. This app extracts raw content and delivers a concise 300-word summary using cutting-edge language models.

---

## 🚀 Features

- 🔗 Summarize any **website** or **YouTube video** with a valid URL
- 🧠 Powered by **Groq's Gemma 2-9B** LLM for fast and intelligent summarization
- 🧰 Uses LangChain's summarization chain with customizable prompt templates
- 🔐 Secure **Groq API key** input through Streamlit sidebar
- ⚡ Real-time summarization with a responsive and clean UI

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **LangChain**
- **Groq API (Gemma 2-9B model)**
- **UnstructuredURLLoader**
- **YoutubeLoader**
